##### **Core Competencies Covered**

- Shell & File System Navigation: Mastering the Linux directory hierarchy, file descriptors, standard I/O redirection, and text processing (grep, awk, sed)
- Permissions & User Security: Managing user/group privileges (chmod, chown, sudoers) and securing system access.
- Process & Service Control: Monitoring system resources, handling background jobs, and managing daemons with systemd.
- Task Automation & Scheduling: Writing foundational Bash scripts and automating recurring jobs via cron.
- Networking & Remote Access: Configuring network interfaces, diagnosing connectivity, and managing remote hosts securely over SSH.

###### Next Milestone

Transitioning these core CLI and Bash skills into automated CI/CD pipelines and containerized DevOps workflows.
